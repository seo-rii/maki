# Round-9 audit probes (main 27cc86e with #387 and #388 merged in)

Reproductions and harnesses from the ninth audit, which looked at the tree
after the eighth round's ten fix pull requests (#379 to #388) by angle. The
Rust tests are the `audit9_*.rs` files under the crates' `tests/`
directories; several fail on purpose on the audited tree (they demonstrate a
finding), and the sweeps are `#[ignore]`d or take seed counts from the
environment.

- `r8-storage/`: real-plugin kill and power-loss probes for creation and
  attach (`native/*.py`). The finding that a shard-catalog copy accepted from
  the page cache is never stored again is
  `crates/maki-core/tests/audit9_catalog_k01.rs` and
  `audit9_unproven_after_damage.rs`.
- `rollback-native/`: a two-filesystem power-loss shim (`plshim2.c`), local
  and remote rollback image sweeps (`rpl.py`, `rrpl2.py`; `rrpl.py` is the
  first version, whose log handling was wrong), attack and concurrency
  probes, the witness probes and a three-member etcd harness (`etcdq.py`,
  which needs an etcd 3.6 release binary).
- `providers-native/`: endpoint servers and drivers for the HTTP, WebSocket
  and gRPC providers under nbdkit (TLS matrix, stall, misbehaving endpoints,
  chaos, log injection). The gRPC TLS 1.3 classification finding is
  `crates/maki-crypto-grpc/tests/audit9_mtls_refusal_class.rs`.
- `control-cli-docs/`: control-socket clients (hostile, races, permissions,
  counters), damaged-volume and configuration probes, and the probes of the
  CLI and documentation findings.
- `r8-privileged/`: the `--plan` probe and the CentOS Stream 9 package
  transaction scripts. The device-move tests are
  `crates/maki-privileged/tests/audit9_device_move.rs`, which compiles the
  helper's sources by path through `tests/audit9_mirror/` (symbolic links into
  `src/`; do not run `rustfmt` on it).

Test certificates and keys are generated by the probes at run time and are
not kept here.
